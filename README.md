# A/L Smart Study

Sinhala-language Android study app scaffold for A/L 2026, 2027 and 2028.

## Current status

This is a starter scaffold, not a complete study-content release. It currently provides:
- Year selector (2026, 2027, 2028)
- Subject selector (Sinhala, Geography, Political Science)
- Local notes saved separately by year and subject
- JSON backup and restore for notes
- A placeholder past-paper year selector (2007–2026)

## Important content policy

Syllabuses, lessons, past papers, answer keys and marking schemes must be checked against official National Institute of Education (NIE) and Department of Examinations sources before being added. No placeholder content should be represented as official or verified. MCQ auto-marking must use verified official answer keys; written responses require verified marking rubrics or should be labelled for self/teacher assessment.

## Build

GitHub Actions builds a debug APK on pushes to `main` or via manual workflow dispatch. Open the Actions tab and download the `al-smart-study-debug-apk` artifact after a successful run.
